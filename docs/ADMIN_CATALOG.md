# Администратор каталога

Для работы в браузере нужна учётная запись с ролью ADMIN. Первого администратора создаёт явная tools-команда после миграции: [локальный запуск](GETTING_STARTED.md). Раздел «Каталог и источники» показывает опубликованные версии, черновики, данные моделей, предложения, источники и нормы.

## Редактирование

Создайте черновик от опубликованной версии с новым уникальным кодом. Добавляйте или правьте модели, предложения, характеристики, источники и нормы в соответствующих разделах. Неизвестная цена остаётся пустой; цену, валюту, НДС и включённые услуги храните у предложения, а не у модели. Указывайте источник каждого утверждения и дату, если она известна. Встроенная загрузка принимает только ограниченный UTF-8 JSON формата `admin-catalog-v1`, затем создаёт черновик и diff; она не выполняет код, формулы или макросы.

Проверьте diff, запустите «Проверить версию», затем «Опубликовать версию». Публикация делает версию неизменяемой, но **не переключает** активный каталог. При изменении черновика после проверки валидируйте его повторно. Владелец черновика выполняет мутации и публикацию; другие ADMIN могут создать свой черновик от published.

## Активация

Слоты независимы: `discovery` — просмотр карточек, `capacity` — новый физический расчёт, `runtime` — старые маршруты. Для переключения discovery и capacity в интерфейсе выберите опубликованную версию, проверьте показанные readiness, полноту, diff и текущие указатели, затем подтвердите переключение. Сервер сравнивает физический пул с утверждённой политикой; новые информационные модели или изменение физических фактов не становятся расчётными автоматически. Для изменённого пула требуется отдельное принятое разрешение. История активаций и возврат к прежней опубликованной версии доступны в аудите.

Organizer bundle не содержит допустимого legacy `runtime` пула, поэтому этот слот не следует активировать ради обхода ограничения. Его отсутствие оставляет старые маршруты недоступными. Economics route — отдельная активация и не меняется вместе с каталогом.

## API и защита

`/api/admin/catalog` предоставляет list/read, создание и изменение черновика, JSON import, validate, publish, activate и audit. Точные тела запросов описывает [OpenAPI](API.md). Все методы требуют ADMIN session; мутации требуют CSRF. Конфликт версии или изменившегося активного указателя возвращает 409. Сохранённые старые расчёты не переписываются после переключения каталога.
