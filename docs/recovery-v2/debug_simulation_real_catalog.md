# G0 — запуск трёх готовых примеров на реальном локальном каталоге

20.10.2026. Среда: локальный FastAPI, изолированная PostgreSQL 17, опубликованный и активированный `organizer-catalog-v4` для `capacity`/`discovery` (187 моделей, 223 позиции). Это не production-проверка. Сеть браузера записана без cookie, паролей и тела запросов в `evidence/local-catalog-examples.json`.

| Пример | Реальный API | Движение 3D и 2D | Деньги/PDF |
|---|---|---|---|
| Склад | template и preview HTTP 200 | поза меняется, пауза держит её | пять шагов, PDF 200 |
| Аэропорт | template и preview HTTP 200 | поза меняется, пауза держит её | переход заблокирован: нет подтверждённой runtime-модели |
| Клиника | template и preview HTTP 200 | поза меняется, пауза держит её | пять шагов, PDF 200 |

Диагноз воспроизведённого сбоя аэропорта: готовый поток давал больше прежних 4000 событий за 4 часа, сервер возвращал `demand exceeds simulation event limit`, playback не запускался. Предохранительный лимит увеличен до 10000 событий; нагрузка примера теперь рассчитывается без семплирования, а более высокая нагрузка по-прежнему семплируется **только для геометрии** с `fleet_required=null` и флагом `DEMAND_SAMPLED_FOR_GEOMETRY`. Профильные тесты 9/9, повторный браузерный запуск трёх примеров 3/3 PASS.

Отсутствие подтверждённой runtime-модели у аэропортового примера нельзя исправлять выдуманными характеристиками. Маршрут виден как сценарный, неподтверждённая экономика не показана как достоверная. Следующая внешняя проверка: безопасно сверить активную production PostgreSQL и официальный runtime-каталог, затем повторить три готовых примера и финансовый переход.
