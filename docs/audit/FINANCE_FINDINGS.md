# Финансовая сверка FINAL FIX V2

Backend не считает отсутствие тарифа аренды нулевым тарифом: поле первого года в report view равно `null`, если расход неизвестен. При известном тарифе разовые вложения (`t=0`) и ежегодная аренда (`t=1,2,…`) разведены. Для тестового тарифа 100 000 ₽/месяц годовой расход составляет 1 200 000 ₽; проверено в `backend/test_role_report_view.py`. Прежний «0» в UI обозначал разовый CAPEX аренды до старта, но подпись выглядела как расходы первого года; подпись и PDF уточнены.

Три DEMO используют расчёт backend из полных входов `frontend/src/showcasePresets.json`, а не зашитые итоговые KPI. Одна работа на объект: перевозка паллет, обработка багажа, доставка лекарств. Цены/выработка/зарплаты являются явно помеченными сценарными предположениями, робот `SCENARIO_TYPE` не означает подтверждённую модель. Склад и клиника показывают положительный NPV выбранной базы; аэропорт может показывать отрицательный результат. Формулы не корректировались ради положительного вывода.

Симуляция влияет на рассчитанный парк и отчётный контекст через серверный preview. Множители 1×/2×/4×/8× — только скорость playback, без пересчёта денег. Локальный browser E2E использовал изолированную PostgreSQL и активированный опубликованный bundle; это не подтверждает production.
