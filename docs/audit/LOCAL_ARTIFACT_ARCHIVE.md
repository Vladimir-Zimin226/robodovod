# Локальные файлы вне релизного Git, 21.10.2026

После фиксации исходников, презентации и проверенных QA-снимков оставались 221 неотслеживаемый файл в `docs/handoff`, `docs/planning`, дополнительном `docs/qa`, старом `docs/recovery-v2/evidence` и других исторических папках. Они **перемещены без удаления содержимого** в `Разобрать/local-worktree-archive-2026-10-21/` с сохранением относительных путей. `manifest.json` в этом каталоге содержит исходный путь, архивный путь, размер и SHA-256 каждого файла. `Разобрать/` уже исключён из Git.

Локальные `.tmp-*`, `.pytest-*`, `.chrome-*` и `frontend/.tmp-*` остались на месте: среди них есть профили браузера и данные изолированной PostgreSQL. Они явно игнорируются Git как рабочие артефакты. Их нельзя добавлять в release bundle или удалять во время работы локальных служб. Новый `git status --short` после коммита этого описания должен быть пустым, хотя сохранённые локальные артефакты физически остаются в рабочей папке.

Для возврата отдельного файла скопируйте его из архива по пути из `manifest.json`; текущие релизные исходники и committed QA-доказательства находятся в обычных каталогах репозитория.
