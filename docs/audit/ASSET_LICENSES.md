# Происхождение визуальных и аудиоассетов

`frontend/public/images/{hero_banner,object_warehouse,object_airport,object_clinic}.webp` предоставлены заказчиком в пакете FINAL FIX V2 для этого проекта. Отдельный текст лицензии в пакете не найден; перед передачей третьим лицам проверить права на сами изображения.

Музыкальная композиция `Dead morose WMD 2.wav` предоставлена заказчиком. В переписке 20–21.10.2026 заказчик прямо подтвердил права на использование в публичном трейлере. Web MP4 содержит AAC; исходный WAV в web-ассеты не включён. Объём предоставленного разрешения для дальнейшей перепродажи/сублицензирования не документирован здесь.

WebGL/GLB сцены и старые текстуры созданы в рамках предыдущих итераций; журнал происхождения находится в `docs/recovery-v2` и `docs/visual-polish`. Для внешней дистрибуции каждого стороннего ассета отдельно требуется сверить документы/лицензию; отсутствие записи здесь не означает CC0.
