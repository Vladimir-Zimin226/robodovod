# Уборка перед передачей

Проверка начата с Git baseline и поисков ссылок. Из текущего frontend удалён неиспользуемый `sceneCapture.js`: App больше не прикладывает скриншоты 2D/3D к инвестиционному PDF, а документ выводит маршрут и допущения текстом. Сохранён optional snapshot-параметр PDF API ради совместимости внешних клиентов; убирать его без проверки внешних вызовов нельзя.

`backend/calculation/readable_report.py` получил явный вертикальный spacer между блоками покупки и аренды; переснятые 3 PDF по 4 страницы показывают обе строки без наложения. `role_report_view.py` остаётся источником цифр UI/PDF. Компактные словари человекочитаемых статусов добавлены только в затронутые UI и PDF. Никакие каталоги, миграции, БД, GLB, трейлер и старые handoff-артефакты не удалены.

Остальной монорепозиторий имеет динамические маршруты и историю; массовое удаление по одному поиску было бы недоказанным. [Журнал удаления](REMOVAL_LOG.md), [долг](TECH_DEBT_BACKLOG.md), [QA](../qa/final-home-demo-fix/FINAL_REPORT.md).

Контрольные поиски после правки: в live `frontend/src` и `robcraft/src` не найдено `console.log`, `console.debug` или `debugger`; среди 1618 Git tracked путей не найдено `dist/`, `node_modules/`, `__pycache__/`, `.tmp` и `.log`; в `frontend/src` и `backend` не обнаружены `TODO`/`FIXME`. Это не является проверкой отсутствия неиспользуемых динамических вызовов или CSS-классов. Внешние интеграции и архивы не удалялись без доказательства.
