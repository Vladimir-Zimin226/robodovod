# Документация РОБОДОВОДА

Здесь собраны документы для запуска и понимания действующего проекта. Начать можно с [запуска](GETTING_STARTED.md), затем открыть [руководство пользователя](USER_GUIDE.md). Код и краткое описание продукта находятся в [корневом README](../README.md).

| Задача | Документ |
| --- | --- |
| Запустить локально и проверить готовность | [Быстрый запуск](GETTING_STARTED.md) |
| Пройти путь пользователя и администратора | [Руководство](USER_GUIDE.md) |
| Понять компоненты и хранение результатов | [Архитектура](ARCHITECTURE.md) |
| Найти маршруты, схемы и правила доступа | [API](API.md) · интерактивная OpenAPI-спецификация локального backend `/docs` |
| Проверить источники формул и границы расчётов | [Расчёты](CALCULATIONS.md) · [проверки и ограничения](VALIDATION.md) |
| Прочитать методологию целиком | [Страница методологии в прототипе](https://robodovod.ru/#economics-methodology) · [проверка исходного документа](delivery/evgeny-feedback-2026-09-28/METHODOLOGY_REVIEW.md) |
| Развернуть в исходном production-окружении | [Инструкция по развёртыванию](PRODUCTION_DEPLOYMENT.md) |

Материалы для показа: [презентация PDF](presentation/Robodovod-ZMNCRAFT-2026.pdf), [редактируемая PPTX](presentation/Robodovod-ZMNCRAFT-2026.pptx), [происхождение слайдов](presentation/SOURCES.md). [Поля формы сдачи](SUBMISSION.md) собраны отдельно; форма не отправлялась автоматически. [Пример инвестиционного отчёта](examples/sample-warehouse-investor.pdf) относится к прежнему авторскому сценарию и не демонстрирует новый полный проектный расчёт.

`docs/planning/` хранит планы и исследования, `docs/delivery/` — архивы выпусков и протоколы проверок. Документы с датой в имени отражают состояние на эту дату; навигация по действующему комплекту начинается здесь.
