# РОБОДОВОД — актуальный контекст для параллельной работы

Срез к выпуску 17.10.2026. Это контекст по локальной версии проекта и изображения локальных сборок. Факт развёртывания на `robodovod.ru` следует проверять отдельно. Реального чертежа склада у команды нет; учебная планировка создана по открытым референсам.

## Порядок чтения

1. [01_PRODUCT_AND_JOURNEY.md](01_PRODUCT_AND_JOURNEY.md) — продукт, пользовательский путь и устройство кода.
2. [02_ECONOMICS_AND_TRUST.md](02_ECONOMICS_AND_TRUST.md) — расчёты, данные, границы достоверности.
3. [03_VISUAL_REVIEW.md](03_VISUAL_REVIEW.md) — изображения, сделанное и задачи для следующего дизайна.
4. [04_WEB_CHATGPT_BRIEF.md](04_WEB_CHATGPT_BRIEF.md) — готовый запрос для веб-версии ChatGPT.

Папка `screenshots/` содержит 20 изображений. Имена `legacy-*` обозначают кадры конца сентября, `oct16-*` — первую итерацию после консультации, `oct17-*` — позднейшие кадры крыши, конструктора и ролей. Ни один снимок не подтверждает состояние production. Изображений последней доработки экономической формы пока нет; её состояние описано по коду и тестам.
