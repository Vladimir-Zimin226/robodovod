# Проверка интерфейса склада · 17 октября 2026

Снимки локальной production-сборки после доработок:

- `warehouse-roof-demo.png` — первый 3D-ракурс готового примера: полноценный фасад и крыша. При переходе камеры внутрь крыша скрывается для обзора операций.
- `warehouse-dxf-import.png` — импорт учебного DXF с выбором единиц и типа каждого слоя.
- `warehouse-constructor-volume.png` — объёмный эскиз импортированного плана; осевые линии слоя `RACKS` показаны как стеллажи.
- `warehouse-roles.png` — ввод склада через роли сотрудников.

Файл для проверки импорта: [`frontend/public/examples/warehouse-training-plan.dxf`](../../../frontend/public/examples/warehouse-training-plan.dxf). Это придуманная схема 72 × 48 м, не чертёж реального склада. Импортёр добавляет по 2 м отступа с каждой стороны; отображаемый размер — 76 × 52 м. Импортированная геометрия сама не создаёт точки приёмки и отгрузки: их нужно отметить на плане, после чего подтвердить расстояние для нового расчёта.

3D-оболочка и детализация стеллажей — визуальные элементы. Сохранённые физический отчёт и экономика от них не пересчитываются. Отдельная роль фасовщика пока отсутствует в расчётном контракте; упаковщик есть для операции паллетизации.
