# Поля формы «Для финальной сдачи» · ZMNCRAFT

Сверено с оригинальным `Разобрать/Материалы от организаторов/Для финальной сдачи.png`.
В форме есть четыре обязательных адреса и необязательные «Дополнительные
материалы». Снимок не задаёт лимит файла, формат видео или обязательность
дополнительного вложения.

| Поле | Адрес для копирования | Состояние |
| --- | --- | --- |
| Команда | `ZMNCRAFT` | Подтверждено скриншотом команды. |
| Репозиторий * | `https://github.com/Vladimir-Zimin226/robodovod` | Адрес `origin` подтверждён локально; доступ проверяющему зависит от открытия репозитория владельцем. |
| Документация * | `https://github.com/Vladimir-Zimin226/robodovod/blob/main/docs/README.md` | Публичный индекс запуска, руководства, архитектуры, API, расчётов и проверок. Доступ проверяющему зависит от видимости репозитория. |
| Презентация * | `https://github.com/Vladimir-Zimin226/robodovod/blob/main/docs/presentation/Robodovod-ZMNCRAFT-2026.pdf` | PDF по шаблону организаторов; рядом [редактируемая PPTX](presentation/Robodovod-ZMNCRAFT-2026.pptx). Доступ зависит от push и видимости репозитория. |
| Прототип * | `https://robodovod.ru/` | Пользователь сообщил об успешном развёртывании после commit `1190c96`; перед отправкой нужно проверить адрес в браузере. |
| Дополнительные материалы | `https://github.com/Vladimir-Zimin226/robodovod/blob/main/docs/examples/sample-warehouse-investor.pdf` | Необязательный исторический пример с прежним денежным охватом; для показа нового результата лучше использовать свежий экспорт из сервиса. |

Форма не отправлена. До отправки владелец публикует проверенный commit в
`origin/main`, открывает репозиторий в нужный момент и проверяет четыре адреса
из внешнего браузера. Состояние production и живого прототипа проверяется
отдельно; локальные тесты не равны проверке развёрнутого выпуска.

После изменения структуры документов ссылки выше начнут работать только после
публикации соответствующего commit. Прежняя ссылка на
`docs/delivery/evgeny-feedback-2026-09-28/README.md` останется указателем на
этот индекс; прежний прямой адрес PDF заменён новым путём выше.
