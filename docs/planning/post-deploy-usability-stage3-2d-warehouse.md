# Этап 3: схематичный 2D-склад

В складском `TRANSPORT_CYCLE_V1` 2D показывает зоны, стеллажи, проходы, приёмку,
отгрузку, ожидание/зарядку и отдельную полосу движения каждого робота. Паллета
проходит точки подбора и выгрузки; этап движения и состояние груза видны для
каждого робота. Для остальных профилей прежняя визуализация сохранена.

`sceneBindingsV2` задаёт общие для 2D и RobCraft идентификаторы зоны, задания,
маршрута, подбора и выгрузки. Выбор зоны в 2D передаётся в 3D по протоколу
активной ревизии; выбор в 3D возвращается в 2D. Выбранная зона сохраняется в
`sessionStorage` под ключом ревизии и digest отчёта, поэтому при повторном
открытии в той же вкладке привязка восстанавливается. Чужую или устаревшую
ревизию RobCraft не принимает.

План условный: `ScenarioSpec` содержит ссылку на PROVIDED-геометрию, но не
содержит координат, пригодных для нанесения на 2D. Интервалы и фазы движения
показывают порядок операций и воспроизводятся из seed/ID/времени; они не
подменяют фактическую длительность, телеметрию или выполненные C23 задания.
Зарядный цикл тоже не моделируется. KPI берутся только из C23 SimulationReport.
При отсутствии задачи/маршрута робот остаётся в ожидании, причина объяснена
в интерфейсе.

Проверено на сохранённом складском ScenarioSpec v2 и отчёте C23 v2: golden
capture при 5 секундах, шесть этапов перевозки, 10 роботов без пересечения
полос, две зоны без пересечения, одинаковые ID в 2D/3D, replay при одинаковом
времени, отсутствие маршрута и координат. Локально просмотрены кадры в Chrome
на широкой панели и в панели шириной 350 px; на узкой ширине план прокручивается
по горизонтали, а текст и состояния роботов остаются внутри панели. Исторические
immutable runs не изменялись. Сервер в рамках этапа не обновлялся.
