# P5 — знак и иконки

## Что изменено

Авторский пиксельный робот с бирюзовыми глазами и зелёной отметкой проверки построен из одного набора фигур в `frontend/scripts/generate_brand_icons.py`. Из него получены SVG, ICO (16/32/64), PNG 16/32/64, Apple 180 и иконки 192/512. У знака тёмная подложка и светлый контур для обеих тем вкладки. Он добавлен рядом с названием в навигации и в футере; в мобильном меню размеры уменьшаются. У словесного названия есть доступное имя, декоративные копии знака не дублируют его для экранного диктора. Manifest и ссылки HTML добавлены для сохранённой страницы.

## Проверки и предел

Размеры всех PNG и три размера ICO сверены через Pillow. Сборка Vite прошла. Скриншот собранной локальной версии в Chrome 1365×900 показал читаемый знак и отсутствие смещения боковой навигации. Скриншот Edge 390×844 показал закрытое мобильное меню и отсутствие смещения его кнопки. Внешний вид раскрытого мобильного меню, вкладка и сохранённая страница на физическом устройстве пока не проверены; это остаётся для P6/ручной приёмки. Production не обновлялся.
