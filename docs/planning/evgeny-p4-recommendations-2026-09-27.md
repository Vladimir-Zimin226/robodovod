# P4 — подбор моделей

## Что изменено

- Главный экран больше не скрывает каталог до объяснения. Он показывает число позиций, причины исключения, статус `REQUIRES_CHECK`, информационные RND и позиции без формулы.
- После ввода физических параметров, выбора проекта и подтверждения демо-допущений сервер без записи run пересчитывает все позиции того же физического профиля на общих входах. Экран показывает предварительного технического лидера, до трёх альтернатив, балл и причины; ручной выбор сохраняется в C11 как прежде.
- Сравнение сохранённого C11 теперь допускает и одну позицию, показывает причину информационного статуса при ручном добавлении. Финансовый вывод по одному изделию остаётся неполным.
- Убрана ложная подстановка подтверждённой поддержки объекта и процесса в C19: отсутствие доказательства остаётся неизвестным.

## Диагностика и результаты

Точного расчёта Жени с привязкой к автору нет. Локальный backend не имеет активированного capacity-слота (`CAPACITY_SOURCE_NOT_ACTIVE`), поэтому живой ответ API для его экрана не установлен. Копия `backup/` прочитана без изменения: в активированном там каталоге 223 позиции и 187 моделей, 25 позиций транспортного профиля, 17 строк с явным сценарием «Внутрискладская логистика», из них 13 с формулой и не RND. Уборка: 13 позиций профиля, 5 с формулой и не RND. Паллетация: 2 позиции профиля, ни одна без блокировки расчёта. Эти числа описывают сохранённую копию, а не результат API фильтра по объекту, массе, проходу и подтверждённости.

В воспроизведении 220 паллет/сутки, плечо 120 м, подтверждённая масса 800 кг: синтетическая позиция с доказанной грузоподъёмностью 1200 кг не исключена, парк рассчитан с демо-допущениями; неизвестная цена явно остаётся причиной и финансовый вывод неполон. Для 2000 паллет/сутки и 120 м см. P1–P3 и итоговую приёмку P6. Точный выбор из копии при массе 800 кг без активного API и подтверждённого паспорта склада не утверждается.

Проверки: `backend/test_candidate_comparison_api.py` — 11 passed; frontend — 141 passed; ESLint и сборка прошли. Проверка в браузере и сравнение ответа живого API с экраном остаются для P6.
