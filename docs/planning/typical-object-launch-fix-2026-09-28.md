# Исправление запуска типовых объектов и меню — 28.09.2026

## Причины и изменения

1. **Аэропорт:** preview сравнения возвращал 500. `PenaltyContextV1`
   принимает `M2`, а нормализованный ввод уборки содержит `SQUARE_METER`.
   На границе сравнения добавлено соответствие единиц. Формулы и объём
   51 000 м² не изменены.
2. **Клиника:** форма искала только `DELIVERY_CYCLE_V1`, которого нет
   в действующем approved capacity-пуле. В read-only backup среди подходящих
   клинике активных позиций доступны два транспортных профиля Ronavi H1500/H2000.
   Предварительный ввод теперь принимает также `TRANSPORT_CYCLE_V1`.
   Только для подтверждённого `PRELIMINARY_DEMO` сервер привязывает к новому
   запросу типизированный профиль доставки: те же зависимости скорости,
   грузоподъёмности и физические формулы, спрос остаётся `portion/day`.
   Каталог и состав approved pool не изменяются. Связь записана как допущение
   в trace. Данные о применимости не появляются из этой связи: неизвестные
   возможности остаются UNKNOWN, явные ограничения производителя блокируют
   расчёт. Обычный VERIFIED запрос такой привязки не получает.
3. **Подбор:** лидер выбирается только среди доступных форме позиций.
   Ранее preview мог предложить лидера вне отфильтрованного объекта, поэтому
   селектор оставался пустым. Около заблокированной кнопки теперь показано,
   нужно ли подтвердить допущения или выбрать модель вручную. При недоступности
   preview ручной выбор сохраняется. Подтверждение партии клиники теперь
   говорит о порциях, а не паллетах типового склада.
4. **Меню:** desktop sidebar имел фиксированную высоту без прокрутки,
   его flex-элементы сжимались, а нижние пункты выходили за экран.
   Добавлены собственная прокрутка, высота текущего viewport (`dvh`),
   запрет сжатия секций и `align-self: start` для sticky-панели.
   Длинная страница не уводит меню вниз. Мобильное меню продолжает закрываться
   после выбора пункта.
