# F6 — скорость и надёжность диалога ИИ

**Статус: реализовано и проверено локально 26.09.2026. Живой latency YC в этом
прогоне не измерен; цель типового ответа ≤15 с остаётся внешней метрикой, а
не заявленным SLA. Production не обновлялся.**

Brain сохраняет сообщение и версию профиля перед вызовом DeepSeek V4 Flash.
Ответ привязан к версии и идентификатору попытки: ручное изменение профиля,
новая попытка или истёкшее ожидание исключают применение старого ответа.
Повтор берёт исходный текст из сохранённой версии, не создаёт новый пользовательский
turn и не использует текущий черновик. После перезагрузки GET показывает `PENDING`,
интерфейс опрашивает результат и восстанавливает черновик из sessionStorage.
Через 70 с осиротевший `PENDING` становится `TIMEOUT` и доступен для повтора.
Ручное редактирование остаётся доступным при fallback.

Пользователь сразу видит статус сохранения/отправки; после пяти секунд — счётчик
ожидания и объяснение. Timeout, отказ и локальное действие имеют отдельные
`model_status=TIMEOUT/FALLBACK/LOCAL`; `HTTP 200` fallback не учитывается как
успех модели. В лог пишутся статус, тип отказа, HTTP-код провайдера, `finish_reason`,
известные токены, время подготовки, провайдера, проверки JSON и сохранения.
Сообщение пользователя, prompt, ключ и сырой ответ в операционный лог не попадают.
Внешнее ожидание ограничено 59 с на уровне запроса; сетевые connect/read лимиты
5/50 с дополняют этот предел. Поздний ответ рабочего потока не пишет в БД.

Контекст сохранённого профиля удалён из provider prompt: извлечение опирается
только на новое сообщение, а проверка и version binding остаются на сервере.
Узкие действия «запустить расчёт», «создать PDF», «что дальше» обрабатываются
локально без YC. Явные числа по-прежнему распознаёт локальный parser, в том
числе при отказе модели. Используются официально описанные для AI Studio
`temperature=0.1`, `max_tokens=5000`, `response_format=json_schema`, `stream=false`;
ответ с `finish_reason=length` и невалидный JSON никогда не считается успехом.
Основная модель `gpt://<folder>/deepseek-v4-flash` подтверждена
[документацией YC](https://yandex.cloud/ru/blog/yandex-ai-studio-deepseek-v4-flash),
параметры — [справкой AI Studio SDK](https://yandex.cloud/ru/docs/ai-studio/sdk-ref/sync/chat/completions).

Три обезличенных диалога [измерены синтетическим прогоном](assets/f6/probe.json):
склад 220 паллет/сутки и 120 м, аэропорт с уборкой 10 000 м², клиника с
перевозкой 35 тележек. Длина JSON-запроса 4 072–4 088 байт против
4 505–4 521 байта с прежним контекстом двух полей (−433 байта); собственное
время `_call_model` 1,94–4,44 мс, проверка JSON 0,01–0,31 мс. Usage
760 input + 45 output токенов **задано заглушкой**, а не измерено у YC.
При этих условных токенах оценка по [опубликованным тарифам YC](https://yandex.cloud/ru/blog/yandex-ai-studio-deepseek-v4-flash)
составляет 0,7515 ₽ за три вызова или 2,505 ₽ за десять. Фактически
внешних запросов в исследовательском прогоне — **0 из лимита 10**. Синтетика
проверяет контракт/overhead, но не качество реальной генерации и не задержку YC.

Проверки: `backend/test_brain_api.py` покрывает успех, 400/401/403/429/500/503,
сетевой timeout, общий предел ожидания, `length`, невалидный JSON и локальное
действие. `backend/test_brain_integration.py` на изолированной PostgreSQL 17
проверяет сохранение, fallback, retry, stale version, перезагрузку во время
ожидания и ручную правку. Совместный прогон Brain, C11, C14 и симуляции —
**181 passed**. Frontend — **135 passed**, lint и production build прошли.
Ни одна историческая immutable запись run, snapshot, checksum или simulation
artifact не переписывалась. Демо и числовое ядро доступны без YC.
