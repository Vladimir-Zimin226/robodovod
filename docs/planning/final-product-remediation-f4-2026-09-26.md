## Результат

`catalog-selection-v1` строит read-only проекцию активного discovery-каталога.
Taxonomy содержит объект и процесс из applicability/use case и точного
расчётного профиля. Отраслевая метка остаётся поисковой подсказкой: она не
подтверждает C05 применимость. Неоднозначность остаётся `UNKNOWN`.
Процессы берутся из неизменного `calculation-process-catalog-v1`, включая
справочные процессы аэропорта и клиники; unsupported не получает формулу.

`/api/catalog/models` и UI используют одни query, фильтры и порядок: объект,
процесс, семейство, тип, производитель, зрелость, доступность, расчётная
готовность, качество проверенных ТТХ, цена RUB, грузоподъёмность kg, проход m.
Сброс показывает весь каталог. Неизвестное числовое значение не становится
нулём и включается только отдельным переключателем. Выбор полей контекста
проекта (масса груза) и ручные ограничения попадают в C05. Сервер возвращает
`INCLUDED`, `EXCLUDED` или `REQUIRES_CHECK`, причины, проверки, единицы,
версии правил и refs источников. Ограничения аэродромной/закрытой зоны,
санитарной обработки, работы вне помещения и протоколов доступа доступны
отдельно; неподтверждённая возможность не проходит как PASS.
Технический вклад C19 по сохранённой операции
остаётся в действующей панели сравнения кандидатов; без C11 числовой рейтинг
физически разных классов не строится.

Известная неподходящая масса/ширина прохода даёт `EXCLUDED`; отсутствие,
конфликт и непроверенный источник дают `REQUIRES_CHECK`. Списки возможностей
и integrations используются только при точном поле с matching-safe evidence;
описание не превращается в физический факт. Ручное сравнение сохраняет снимок
статуса/причин выбранной карточки при дальнейшей смене фильтров и прямо
помечено как информационное, без рекомендации к закупке. В матрице 2–3
позиций видны units и evidence IDs.
Новый C11 тоже применяет подтверждённую грузоподъёмность к введённой массе
единицы груза: известное превышение блокирует новый run, неизвестная
характеристика остаётся на проверку. Позиции со стадией RND сервер не
допускает к новому capacity-расчёту. Это не меняет сохранённые C11 snapshots.

Ручной ввод и Brain предлагают весь совместимый активный calculation-ready
пул, а не только три авторских демо. RND и неподдерживаемый физический профиль
не становятся вычисляемыми от выбора пользователя; прежние демо-паспорта,
ссылки и явно неизвестные условия оставлены. Неизвестные паспорт, проход,
пол, комплектация, условия эксплуатации и цена не дополнялись вымышленными
цифрами. Оверлеи описаний применяются из активной версии локально; проверка
нового выпуска на production остаётся частью развёртывания/F8.

(8000) и Vite (5173):

```cmd
set F4_DATABASE_URL=postgresql://f1@127.0.0.1:5541/stage11_f1_browser
python scripts\browser_f4_acceptance.py
set F1_DATABASE_URL=postgresql://f1@127.0.0.1:5541/stage11_f1_browser
python scripts\browser_f3_physical_acceptance.py
```
