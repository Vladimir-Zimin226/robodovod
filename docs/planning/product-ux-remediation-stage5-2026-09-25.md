# Этап 5: подбор и объяснимое ранжирование

## Реализовано локально

- Добавлен серверный API `candidate-comparison-v1` для одного сохранённого C11 run. Он проверяет владельца проекта, контрольные суммы ввода, результата, trace и привязок версий, требует активную версию расчётного каталога и пересчитывает выбранные позиции на одинаковых входах. Исторические runs и снимки не меняются.
- Когорта ограничена одной операцией и физическим расчётным профилем. Выбранные пользователем груз, проход и интеграции применяются ко всем кандидатам только после явного подтверждения. Жёсткий C05 отказ, неподтверждённая пригодность, отсутствие формулы, R&D и неизвестные факты различаются до вывода балла.
- Технические компоненты и финансовая нормализация используют формулы C19 `ranking-v2`. Данные R08 заполняются по фактическим статусам и ссылкам каталога; TRL без подтверждённого факта остаётся непроверенным. Ответ содержит вклад компонентов, причины, версии правил, digest общего ввода и ссылочные digest C11/C05/C06 для каждого кандидата. Порядок карточек не влияет на баллы.
- Денежный балл появляется только при двух и более допустимых позициях с полными сопоставимыми финансовыми runs. Проверяются связь каждого run с C11 той же позиции и операции, одинаковые технические входы, одинаковые денежные условия, закупочная готовность и положительность NPV. Неполные или несовпадающие условия оставляют денежный вывод недоступным; неположительные NPV не дают положительной рекомендации. Для паллетной перевозки финансовый run с высвобождением комплектовщика, сортировщика или упаковщика либо с высвобождением сверх численности роли отвергается.
- Интерфейс сравнения добавлен рядом с техническим результатом в «Расчёте» и «Моделировании процесса». Он показывает одинаковые входы, допуск, парк, технический и денежный баллы, причины и источники. Подходящие сохранённые финансовые runs предлагаются в списке по модели, времени, NPV и digest условий; пользователь выбирает их явно. Автоматическая рекомендация к закупке не выдаётся при непроверенной пригодности. Роборука R&D остаётся информационной позицией без парка и NPV.

## Проверки и открытые gates

- Backend тесты этапов C11/C14/C19 и складской цепочки: `66 passed` после последних изменений. Включены два кандидата на 220 паллетах/сутки и 120 м, независимость от порядка карточек, жёсткий отказ по грузу, R&D без парка/NPV, пропущенная и отрицательная экономика, несовпадающие финансовые условия и запрет экономии роли комплектовщика в паллетном маршруте.
- `ruff check` новых модулей и `py_compile` прошли. Golden существующего C19 не изменён.
