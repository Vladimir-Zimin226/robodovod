# Этап 10: «Отчёты»

Локальная реализация от 26 сентября 2026 года. Этап 11 не начат.

## Что сделано

- Самостоятельная страница `#reports` показывает проекты владельца и все сохранённые технические и экономические версии. Старый адрес `#report` ведёт на эту же страницу.
- Версии группируются по сохранённой ссылке на расчёт парка. Для каждой операции отдельно показаны процесс, зона, модель, парк, доступность труда, покупки, RaaS и симуляции. Парки и денежные потоки разных зон не складываются.
- Карточка различает технический, частичный, полный и неуспешный результат. NPV показывается только для рассчитанного базового сценария соответствующей ветки; неизвестный NPV остаётся «не рассчитано».
- Две полосы полноты показывают количество подтверждённых входов и рассчитанных разделов. Это не оценка пригодности решения или вероятности закупки.
- Можно открыть результат, сравнить две версии одной операции, скачать доступные PDF/ZIP через действующий проверяющий экспорт и создать новую версию из сохранённых входов v1–v4 через редактор допущений. UUID, версии правил и digest убраны в «Технические подробности».
- API истории создаёт краткое представление на чтении из сохранённых снимков и `SimulationArtifact`. Проверка владельца проекта остаётся на сервере. Исторические immutable runs, их snapshots и checksums не изменяются.

## Границы

Кнопки PDF/ZIP показываются для успешного run; если для конкретной версии экспорт недоступен, пользователь получает явную ошибку сервера. Новая версия создаётся только после изменения/подтверждения входов и отправки отдельного расчёта. Сквозная приёмка всего продукта, production и публикация относятся к этапу 11 или отдельному выпуску.

Отдельный коммит не создан: `.git` доступен в sandbox только для чтения, а рабочее дерево содержит незакоммиченные результаты предыдущих этапов. В рабочем дереве остаётся созданный ранее `.chrome-stage9/`: Windows отказал в удалении его cache-файлов даже с правами владельца. Автоматический browser gate этапа 10 использовал отдельный одноразовый профиль и удалил его.
