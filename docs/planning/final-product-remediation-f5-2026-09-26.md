## Результат

Новый расчёт сохраняет `commercial-scenarios-bundle-v3` / `financial-comparison-v1`.
В одной таблице показаны baseline, покупка и RaaS за пять лет: состав и статьи
CAPEX, затраты первого года и их изменение, ФОТ, годовой и суммарный эффект,
чистый эффект после вложений, простой срок, ROI, TCO, NPV и дисконтированный
срок. Для двух вариантов роботизации сохраняются BASE/PESSIMISTIC/OPTIMISTIC.
ROI новой таблицы — сумма годовых эффектов **до CAPEX** / CAPEX проекта × 100;
при нулевом CAPEX он N/A. Baseline не является инвестиционным сценарием,
поэтому его ROI и сроки N/A. TCO — CAPEX + затраты сценария за горизонт;
NPV и чистый эффект показаны отдельно. Ранее принятый показатель RaaS на базе
TCO не переименовывался и не подставляется под ROI на CAPEX. Формулы и bases
сохранены рядом со значениями и источниками.

`scenario-sensitivity-v1` хранит для baseline объём, зарплату и ручную
выработку; для покупки — цену, объём и зарплату; для RaaS — тариф, объём и
зарплату. Для каждого из семи представленных вариантов записаны оба изменения
±10%, исходное значение, NPV варианта, дельта и причина непригодности при
невозможности расчёта. В UI переключение выбирает sensitivity именно
отмеченного сценария и профиля. Новая цена gross RUB редактируется с
обязательным источником; ручная выработка и объём редактируются в форме
подтверждённых входов. Изменение создаёт новый run, старый остаётся доступным.

Экспорт `calculation-evidence-export-manifest-v4` собирается только из
проверенных сохранённых snapshots, без нового денежного расчёта. Девять листов
XLSX: «Итог», «Входы», «Оборудование», «Сценарии», «Денежные потоки»,
«Чувствительность», «Источники», «Симуляция», «Ограничения и версии».
CSV имеет русские заголовки, UTF-8 BOM и разделитель `;`. Прямые PDF, XLSX,
CSV и ZIP доступны из результата и истории. PDF повторяет значения таблицы,
показывает дату/версии, предварительность и условную 2D-схему с KPI выбранного
сохранённого C23; автономный `Схема_2D.svg` и `Связь_сценария.json` включены
в ZIP. Manifest связывает run, digest результата, ScenarioSpec, C23 и SVG;
каждый файл проверяется по SHA-256. Выбор чужого C23 отклоняется. Если C23 не
сохранён, раздел явно пуст, схема не выдумывается. Старые runs содержат
`NOT_SAVED` для отсутствующей полной таблицы и не получают скрытый пересчёт.

## Воспроизведение

Из корня репозитория на Windows CMD с локальной одноразовой БД и работающими
backend `127.0.0.1:8000`, Vite `127.0.0.1:5173`:

```cmd
set PYTHONPATH=backend;.
python scripts\build_f5_sample.py
set F5_DATABASE_URL=postgresql://f1@127.0.0.1:5541/stage11_f1_browser
python scripts\browser_f5_acceptance.py
set F1_DATABASE_URL=postgresql://f1@127.0.0.1:5541/stage11_f1_browser
python scripts\browser_f3_physical_acceptance.py
```

Скрипт браузерной проверки отказывает нелокальному адресу/другой БД.
Для production обновления F5 новых миграций или env-переменных не требуется;
деплой и HTTPS smoke остаются отдельной авторизованной работой. F6 — только
после следующей команды пользователя.
