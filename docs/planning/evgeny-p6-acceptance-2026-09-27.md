# P6 — итоговая приёмка P1–P6

## Изменения при приёмке

- Полный прогон выявил несовместимость P2 с установленным Pydantic 2.11: `exclude_if` не исключал новые пустые поля, поэтому менялись сериализация и replay digest старых C14/C15. Добавлены явные сериализаторы, сохраняющие прежний JSON при отсутствии решения о персонале. Исторические fixture, snapshots и checksums не менялись.
- Обновлены привязки исходников публичного справочника формул. Исправлен относительный путь теста аудита каталога, зависевший от текущей папки запуска.
- Информационные процессы без формулы теперь остаются в выборе процесса и открывают каталог; паллетная формула им не подставляется.
- Приёмочный тест PDF/XLSX/CSV дополнен объёмом 2000 паллет/сутки при плече 120 м.

## Неизменность исторических данных

`backup/` использовался только для чтения. В начале P1 и после расчётных проверок P6 все **31/31** файлов совпадают с manifest SHA-256. В 26 исторических runs дополнительно проверены **88/88** ненулевых snapshot/checksum связок; в 7 simulation artifacts — **14/14** request/report snapshot связок, расхождений нет. Git diff от состояния до P1 не содержит исторических fixture и simulation artifacts.

Одноразовая PostgreSQL среда не запускалась: `TEST_DATABASE_URL` отсутствует, локальные службы PostgreSQL остановлены, Docker daemon недоступен. Поэтому сравнение database-level digest до/после операций сохранения на одноразовой БД не выполнено. Файловая проверка read-only копии и replay golden tests эту границу не заменяют.

## Оставшиеся ограничения

Точный run Жени с авторством не установлен; вывод P1 воспроизводит расхождение проекций C16/C18 по имеющимся данным. Локальный активированный capacity-каталог отсутствует (`CAPACITY_SOURCE_NOT_ACTIVE`), поэтому авторизованный end-to-end путь и реальные причины отсечения по массе/проходу пока не подтверждены. Копия каталога и синтетические тесты не повышают закупочную готовность моделей.

Production не обновлялся. Посторонние незакоммиченные `.chrome-stage9/`, пользовательский HTML и исходный план не изменялись. Временные папки браузерной проверки в корне очищены; `frontend/.tmp-p5/` осталась из-за занятого/недоступного `LOCK` Chrome и в коммит не входит. Пользовательские процессы браузера не завершались.

Повтор локальных проверок из Windows CMD:

```cmd
python -m pytest -q backend --tb=short
cd frontend
npm.cmd test
npm.cmd run lint -- --ignore-pattern ".tmp-p5/**"
npm.cmd run build
```

Production smoke после отдельной команды на обновление остаётся обязательным: сохранение C11 → персонал/норма → purchase/RaaS → reopen → PDF/XLSX/CSV, desktop/mobile и реальные каталог/паспорт объекта. Новый backup для этого не требуется.
