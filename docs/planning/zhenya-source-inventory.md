## R00 — 00_METHODOLOGY.md

- Назначение/статус: действующий регламент 3.2; registry описан как будущий
  единый источник. До него R02 отвечает за константы, R06 — за допущения.
- Входы: акт, organizer dataset, vendor passport, экспертная оценка, ввод.
  Выходы: классифицированный параметр с unit/source/version, snapshot проекта.
- Формулы: `NPV_project = NPV_scenario − NPV_base`; прямой труд 1.302,
  фиксированные накладные 0.248; никакого отдельного налогового щита.
- Ограничения: без зарплаты блок не считается; assumptions открыты пользователю;
  никакого двойного учёта; RaaS без остатка/батарей; платежи в TCO/налогах;
  амортизация ограничена сроком; пересчёт только явно.
- Вопросы: фактического registry нет; машинные units, точность, schema и
  подтверждение спорных записей ещё надо зафиксировать.
- Противоречия: заявленный запрет дублей при многочисленных дублирующих
  значениях R02/R06; иерархия источников внутри регламента не превращает
  неподтверждённую ссылку на закон в проверенный факт. «Ограничение по умолчанию
  = потенциал» в прозе уточняется R02 как доля 1.0.
