# Этап 3: «Помощник по сервису»

Локальная приёмка 25 сентября 2026 года после редакции плана `c34f093`.
Этап 3.1 с Robovod Brain не начат.

## Что сделано

- Страница `#assistant` занимает полезную ширину и отвечает только на вопросы о разделах, вводе, допущениях, частичном результате, симуляции и документах сервиса. Старый адрес `#process` перенаправляется на неё. Для ответов введена версионированная база знаний `service-assistant-knowledge-v1`; неизвестный или слишком предметный вопрос получает честную границу ответа и ссылку на подходящий раздел.
- В интерфейсе помощника оставлены один вопрос и кнопка «Отправить». Убраны карточки роботов, сравнение, веб-поиск и расчётное интервью. Справочные действия ведут в демо, расчёт, каталог, проекты или к уже открытому результату. На лендинге «Рассчитать свой процесс» теперь ведёт прямо к действующей форме расчёта.
- Серверный справочный endpoint доступен гостю, ограничен по числу запросов и проверяет владельца проекта и CSRF при передаче `project_id`. Он не изменяет профиль или run. Старые профили интервью, их API и активные расчёты сохранены для переноса в этапе 3.1.

## Проверки

- 14 профильных backend тестов, 115 frontend тестов, ESLint и production build прошли. `git diff --check` без ошибок.
- На одноразовой PostgreSQL 16 Chrome проверил 1366×768 и 390×844: переход со старого `#process`, прямые ответы и неизвестный вопрос, переход к расчёту, Back, мобильное меню, отсутствие горизонтальной прокрутки. Выбранный проект восстановился после обновления страницы; сохранённый ранее черновик интервью не изменился после вопроса помощнику и перезагрузки.
- [Снимки desktop/mobile](assets/stage3) сохранены рядом с отчётом.

Старый пошаговый черновик не показывается на странице справки; новый разговорный расчёт и перенос профилей относятся к этапу 3.1. Исторические immutable runs и snapshots не изменялись. Production не проверялся.
