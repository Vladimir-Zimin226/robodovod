# Этап 4: отдельная страница «Процесс»

Пункт «Процесс» открывает страницу «Помощник по выбору решения — готовим».
Она кратко объясняет будущий сценарий и ведёт двумя явными действиями к
действующему расчёту и библиотеке решений. Расчёт получил отдельный пункт меню;
заголовок его формы теперь «Расчёт сценария роботизации». Видимого названия
«РобоМера» в frontend больше нет.

Переходы между страницами используют различимые hash-маршруты и историю
браузера. Из каталога можно перейти к расчёту или вернуться на предыдущую
страницу. Если результат открыт, со страницы «Процесс» доступен возврат к нему.
Выбранный проект сохраняется при этих переходах, а при открытии расчёта его
базовые входы остаются доступными как исходный набор. Прямая ссылка
`#calculation` открывает форму с допустимым типом объекта по умолчанию.

Проверено в локальном Chrome: страница, обе кнопки, переход из каталога,
browser Back, мобильное меню на 390 px, прямой вход в расчёт. Через локальный
фиктивный API проверены автоматическое восстановление выбранного проекта,
переход в расчёт и обратно, открытие проекта из списка и возврат к странице
«Процесс». Frontend tests, lint и production build проходят. Исторические runs
не изменялись; на сервер эти локальные изменения не выкладывались.
