# U2 — сравнение моделей

Дата: 27.09.2026. Локальная реализация.

## Изменения

- В каталоге кнопка сравнения перенесена в нижнюю панель страницы. Она больше не перекрывает содержимое фиксированным слоем.
- Диалог удерживает фокус, закрывается кнопкой, Escape, нажатием на фон и навигацией Back. При закрытии восстанавливаются фокус и прокрутка; при размонтировании страницы слой убирается.
- На результате показан порядок действий: сохранить расчёт парка, выбрать 2–3 совместимые модели, сравнить. Исходная модель выбрана явно; вторая больше не выбирается автоматически. Видны выбранные названия, пустая когорта, исследовательские/нерасчётные модели, отсутствие сопоставимого финансового run и ошибка API.
- Серверное сравнение остаётся read-only и повторно проверяет владельца, CSRF, одинаковые физические входы и финансовую базу.

## Проверки

- Headless Chrome на production build с synthetic API: 1366×768 и 390 px; Escape, фон, переход, Back, reload, отсутствие общего горизонтального переполнения и сброс `body.overflow` прошли.
- Frontend: 137 passed, ESLint и build прошли. Backend `test_candidate_comparison_api.py`: 8 passed.
- Проверка сохранённого результата 220/120 с реальной одноразовой PostgreSQL пока не проводилась; этот gate остаётся на U5. Исторические runs не менялись; production не обновлялся.
