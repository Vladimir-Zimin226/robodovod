# Этап 12: пользовательская инструкция новой версии

Выполнено локально 26 сентября 2026 года на рабочем HEAD `f75a0c8` с незакоммиченными результатами этапов 3.1–11. Это последний этап обновлённого плана.

## Результат

- Созданы [новое руководство Markdown](../USER_GUIDE_2026-09-26.md) и [PDF для пересылки](../USER_GUIDE_2026-09-26.pdf). Старые [Markdown](../USER_GUIDE_CURRENT_2026-09-25.md) и [PDF](../USER_GUIDE_CURRENT_2026-09-25.pdf) не изменены: они относятся к предыдущему выпуску.
- Руководство даёт роли владельца бизнеса, руководителя проекта и участника обследования, два полных маршрута (публичный типовой склад и свой разговорный профиль), подтверждение единиц за рейс/зон/денежных условий, частичный и полный результат, 2D/3D, «Робоэксперт», словарь формул, историю, PDF/ZIP, статусы и объяснение отсутствующего NPV. Границы перевозки, отбора и упаковки описаны отдельно.
- Шесть иллюстраций desktop/mobile сняты `scripts/capture_user_guide_stage12.py` и `scripts/browser_stage31_brain.py` с текущего локального интерфейса на одноразовой PostgreSQL и Chrome при 1366/390 px. Кадр Brain сделан после ввода 220 паллет/сутки и 120 м, до перехода к типовому складу. Демо, помощник, Brain и история открылись по живым маршрутам; горизонтального переполнения в снятых экранах не было. Тестовая учётная запись на изображениях относится только к одноразовой базе. AI Studio в проверке отключена, поэтому экран Brain честно показывает ручной путь при недоступной модели.
- `scripts/render_user_guide_v2.py` собирает автономный HTML и PDF из Markdown с теми же иллюстрациями. HTML служит промежуточным печатным файлом; поставляемые документы — Markdown и PDF.
- Во время повторного браузерного прогона обнаружены повторяющиеся React keys у соседних блоков результата Brain. В `BrainModelScreen.jsx` ключи секций сравнения, экономического ввода и экспортов разделены по назначению; браузерный сценарий теперь проверяет отсутствие такого предупреждения в консоли.

## Проверка

- Сквозной браузерный сценарий Brain на одноразовой БД повторно прошёл desktop и mobile после исправления: 220 паллет/сутки, 120 м, частичная экономика, «что если», полный типовой склад и PDF. Предупреждений React о ключах нет.
- После исправления frontend: **127 тестов прошли**, ESLint без ошибок и предупреждений, сборка прошла (Vite сообщил только о крупном JS чанке). Python-скрипты прошли компиляцию и Ruff.
- PDF читается `pypdf`: **7 страниц**, **6 встроенных изображений**; извлечён текст обоих маршрутов, 220 паллет, 120 м, «Робоэксперт», NPV и PDF/ZIP.
- Все семь относительных ссылок нового Markdown указывают на существующие файлы. Названия ключевых кнопок сверены с JSX; скриншоты получены с тех же компонентов. Адрес сайта указан как адрес **после публикации**: новая версия на production не опубликована и потому по HTTPS не проверялась.
- Исторические immutable runs и их снимки не изменялись. Созданы только данные одноразовой локальной БД.

## Ограничения

Руководство описывает локальную новую версию, а не живой production. Живой Yandex API и веб-поиск не вызывались. Локальные backend/Vite и PostgreSQL остановлены, каталог одноразовой БД удалён. Отдельный коммит невозможен в текущей sandbox: `.git` доступен только для чтения и в рабочем дереве уже есть изменения предыдущих этапов.
