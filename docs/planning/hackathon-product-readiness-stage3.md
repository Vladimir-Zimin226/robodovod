# Этап 3: 2D/C23 для технического и частичного расчёта

Выполнено 25 сентября 2026 года по плану `hackathon-product-readiness-2026-09-25.md`.

- Новые входы экономики `economics-explicit-inputs-v4` сохраняются в immutable envelope `economics-run-input-v5`. Частичный run при достаточных технических данных получает валидный `scenario-spec-v2` без финансовой привязки. Результат `economics-partial-result-v1` содержит отдельный статус `visualization` и точный список недостающих технических полей. Неполная экономика оставляет NPV `null`; C05 и procurement не повышаются.
- Минимальные входы: доступный C11 с проверенной идентичностью и trace, известная нагрузка и парк, график C11, маршрут для транспортного процесса, явное местное время начала и существующий часовой пояс IANA. Длительность рабочих окон сохраняет часы C11. Задача, парк и маршрут связываются идентификаторами C11. Геометрия без плана обозначена `SYNTHETIC` и не влияет на аналитический маршрут или расчёт денег.
- Экран C11 предлагает время и часовой пояс и создаёт новый дочерний частичный технический run через действующий owner scoped API. Исходный C11 не меняется. Из нового run запускается C23; его report и evidence сохраняются как отдельный неизменяемый artifact и повторно открываются. Для старого частичного run редактор предлагает создать новый связанный run; если исходному C11 не хватает графика или маршрута, экран называет нужные поля. Экран частичного результата явно отделяет доступность схемы от отсутствия денежного эффекта. KPI в 2D/3D берутся только из C23.
- Исторические `economics-explicit-inputs-v2/v3` по-прежнему воспроизводят прежнюю заглушку `scenario-spec-partial-v1`; новые правила включены только для v4. Старые C11/partial snapshots, simulation artifacts и их SHA-256 не переписываются. Полный v4-ввод сохраняет прежний финансовый движок и шесть сценариев.

Проверка: профильные backend тесты проверяют чисто технический ScenarioSpec, успешный C23 без NPV, недостаток часового пояса, неизменное старое поведение и полный финансовый сценарий v4. Интеграционный тест дважды прошёл на разных пустых одноразовых PostgreSQL: создание, exact replay, запуск и сохранение C23, выдача evidence, повторное открытие и неизменные checksum исходных C11/partial runs. Frontend: 105 тестов, lint и production build.

Границы: новый C11 создаёт связанный частичный технический run для 2D; сам исторический C11 snapshot не получает ScenarioSpec. Без графика, маршрута или известной нагрузки потребуется новый C11 после уточнения ввода. Координаты условные, SLA без отдельного задания не оценивается, C23 не является телеметрией или инженерным цифровым двойником.
