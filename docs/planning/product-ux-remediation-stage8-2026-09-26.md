# Этап 8: Робоэксперт

Локальная реализация от 26 сентября 2026 года. Этап 9 не начат.

## Что сделано

- Пункт «Варианты» переименован в «Робоэксперт». Самостоятельная страница доступна по `#roboexpert`; старые ссылки `#variants` и `#scenarios` открывают её же.
- Сервер читает активный discovery-каталог и сравнивает 2–3 расчётные позиции только при совпадении семейства, типа и физического расчётного профиля. Информационные и исследовательские позиции остаются доступными в отдельном списке без числового вывода. Для них объясняется отсутствие расчёта парка; отдельно названы G2P, Pick by Voice/Light и исследовательские комплектовщики.
- Таблица строится по одинаковому набору полей с единицами, статусом доказательств, evidence ID и ссылкой на официальную карточку. Отсутствующие и конфликтующие факты показаны явно. Числа сопоставляются только при общей единице и подтверждённом источнике. Цена получает сравнительный вывод лишь при нормализованной сумме в RUB с подтверждённым evidence status и evidence ID. Иначе интерфейс сообщает, что вывод о дешевизне недоступен. Выводы не утверждают пригодность на объекте.
- При наличии сохранённого C11 проекта на странице показывается прежний рейтинг этапа 5: баллы C19, компоненты, причины исключения, статус расчётной доступности и независимый денежный результат. Он рассчитывается на сохранённых входах и не переписывает run.
- DeepSeek V4 Flash вызывается через серверный Yandex AI Studio только после явного действия вошедшего пользователя. Модели передаются структурированные факты каталога; она не вычисляет баллы, не меняет доказательность и не получает веб-факты. Ответ отображается отдельным блоком с версией модели и оценкой расхода. Недопустимые формулировки об отклонённых сравнительных выводах отбрасываются; при сбое остаётся структурированное сравнение.
- Yandex Search API вызывается отдельно для паспорта, цены, сервиса или доступности выбранной позиции. Результат содержит ссылку, дату запроса и статус «требует проверки», не меняет официальный каталог или расчёт. Для AI и поиска: CSRF, не более двух вызовов в минуту и пяти в день на пользователя, сорока в день на процесс сервера. Это пилотный локальный guard; при нескольких backend-процессах для жёсткого общего лимита понадобится общее хранилище или лимит в Yandex Cloud.

## Проверки и расходы

- Новый API и существующее сравнение: `14 passed`; проверены одинаковый класс, запрет разных типов/профилей и RND, отсутствие вывода о цене без подтверждения, конфликт фактов, устаревший digest AI-запроса, безопасный fallback модели, provenance веб-ответа и лимиты.
- Полный backend suite с временной папкой внутри workspace: **694 passed, 66 skipped**. Ruff `E4,E7,E9,F` и JSX-синтаксис пройдены. Навигационные alias проверены исполнением модуля.
- Frontend/Vite build недоступен в sandbox: `EPERM lstat C:\Users\Владимир Королев`; браузерная проверка desktop/mobile и живого выбора каталога остаётся открытой.
- Проведены по одному минимальному живому вызову AI Studio и Search API с локальным ключом. Оба вернули `unavailable`; отдельная проверка соединения показала `ConnectTimeout` к обоим адресам Yandex. Поэтому фактические токены, ответы и списание в Yandex Cloud в этой среде не подтверждены.
- Оценка AI использует публичный тариф DeepSeek V4 Flash 0,3 ₽ за 1000 входящих и 0,5 ₽ за 1000 исходящих токенов ([Yandex Cloud](https://yandex.cloud/ru/blog/yandex-ai-studio-deepseek-v4-flash)). Для синхронного веб-поиска на 26 сентября использована дневная ставка 488 ₽ за 1000 запросов, то есть 0,488 ₽ за запрос и до 19,52 ₽ при лимите 40 вызовов одного процесса в день ([Yandex Search API](https://aistudio.yandex.ru/ru/docs/search-api/pricing)). Это оценка, не показание биллинга; льготный ночной тариф и договорные условия могут отличаться.

## Статус

Исторические immutable runs и снимки не изменены. В production этап не выпускался. Для полной приёмки нужно открыть страницу на desktop и телефоне, проверить реальный активный каталог и получить по одному успешному ответу AI/Search из среды с доступом к Yandex Cloud, затем сверить расход в биллинге. Отдельный коммит не создан: `.git` в sandbox доступен только для чтения, а рабочее дерево содержит незакоммиченные изменения предыдущих этапов.
