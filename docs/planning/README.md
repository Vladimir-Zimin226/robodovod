# Планы и история разработки

Файлы в этой папке — рабочие планы, исследования, протоколы этапов и первоначальные спецификации. Они фиксируют решения на момент написания и могут расходиться с действующим кодом. Для запуска и проверки используйте [корневой README](../../README.md) и [актуальный комплект](../README.md).

Сюда перенесены прежние корневые `00–19` документы, журнал контекста, рабочий пакет и промежуточный отчёт о сдаче. Остальные файлы `planning/` сохраняют расчётные разборы и историю интерфейсных изменений. Протоколы выпущенных артефактов лежат отдельно в `docs/delivery/`. Старые даты, внутренние коды этапов и ссылки на прошлые интерфейсы в архиве не являются инструкцией к текущему запуску.
