# Этап 9: «Экономика»

Локальная реализация от 26 сентября 2026 года. Этап 10 не начат.

## Что сделано

- Пункт «Экономика» открывает отдельную страницу `#economics` независимо от наличия расчёта. На странице 13 понятий: производительность, парк, базовый поток, CAPEX, OPEX, TCO, труд, окупаемость, NPV, дисконтирование, чувствительность, покупка и RaaS.
- Карточка показывает формулу, единицы, конкретные входы и место их заполнения, числовой пример, применимость, источник данных, раздел результата и идентификаторы правил. Из неё можно открыть расчёт; складской пример доступен отдельной кнопкой.
- Поиск работает по русскому названию, синонимам и обозначениям. Проверены «окупаемость», «NPV», «ЧПС», «цена владения», «раас».
- Числовые примеры создаёт `scripts/build_economics_glossary.py`: он исполняет действующий C11 складского демо и серверные функции финансов покупки и RaaS, затем сравнивает последние два результата с golden fixtures. В артефакте сохранены версии движков, digest результатов и SHA-256 файлов расчётных правил. Режим `--check` выявляет устаревший справочник. Браузер не вычисляет эти формулы.

## Проверки

- `python scripts/build_economics_glossary.py --check` — пройдено.
- Проверка опубликованного справочника против действующих движков и golden fixtures добавлена в backend suite. Вместе с финансовыми, RaaS и orchestrator тестами — **41 passed**.
- Frontend `node --test` для маршрута и поиска — **4 passed**; Vite production build прошёл через `npm.cmd run build`. Обычный sandbox давал `EPERM lstat C:\Users\Владимир Королев`, поэтому эти проверки выполнены с разрешённым доступом к файловой системе. JSX `App.jsx` и страницы также успешно разобран Babel parser.
- `scripts/browser_stage9_glossary.py` прошёл в локальном headless Chrome: открытие `#economics`, 13 карточек, поиск «окупаемость», «NPV», «цена владения», раскрытие формул и полей, отсутствие горизонтального переполнения при viewport 390 px. Дополнительно визуально проверен первый экран desktop 1366 px. Проверка использовала статическую сборку без backend и не проверяла сохранение пользовательского расчёта.

## Границы

Складские значения и golden fixtures — объясняющие примеры, не цена поставщика или результат пользовательского проекта. Справочник не меняет C11/C13–C21, исторические immutable runs и их снимки. Production не обновлялся. Отдельный коммит не создан: `.git` доступен в sandbox только для чтения, а в рабочем дереве есть незакоммиченные результаты предыдущих этапов. Временный ручной профиль Chrome `.chrome-stage9/` остался в рабочей папке: Windows отказал в удалении cache-файлов даже при повторной попытке с правами владельца. Автоматический browser gate использует собственный одноразовый профиль и удалил его.
