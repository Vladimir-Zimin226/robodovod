- `backend/verify_catalog_media_stage1.py` сверил все 223 пары «позиция → страница/слот → SHA-256 → файл» с исходным PDF и фактическими байтами. `/api/catalog/models` вернул media URL для каждой позиции; `/api/catalog/positions/{id}` совпал с карточкой для БАС, БРС и ПО. Во временном хранилище один файл временно скрыли: API дал 404; файл восстановлен.

При блокировке запроса изображения браузер показал явную заглушку «НЕ УДАЛОСЬ ЗАГРУЗИТЬ». Код карточки и диалога теперь отличает такую ошибку от отсутствия медиа в каталоге.
