# Презентация ZMNCRAFT · E9

Редактируемая [PPTX](Robodovod-ZMNCRAFT-2026.pptx) собрана из слайдов 7–20
исходного `ЛЦТ2026 Шаблон презентации.pptx` без изменения оригинала.
Тема, пропорция 16:9, фоновые макеты и логотипы организаторов сохранены;
основные тексты и карточки — редактируемые объекты PowerPoint. PDF создан
установленным PowerPoint 16.0 из этой PPTX, 14 страниц. На каждой странице
проверены кириллица и переносы; PDF встраивает Montserrat.

Титул использует официальную формулировку задачи из плана E9. ФИО, город и
фотографии участников взяты из `Команда и навыки.png`, `Зимин.png` и
`Юрченко.png` в каталоге организаторов. Роли, контакты и образование — из
уточнения пользователя 28.09.2026: Владимир — капитан, AI-product/full-stack,
магистрант ИТМО; Евгений — AI-инженер, vibe-кодер, юрист и студент/выпускник
неуточнённого университета Хабаровска. В слайде указан только
«университет Хабаровска»; статус обучения не заявлен. История знакомства
участников неизвестна, поэтому слайд 4 описывает продуктовую мотивацию и
подтверждённое разделение работ, без биографического сюжета.

Слайды 2, 5, 7–10, 12–13 основаны на коде после E8, новом
[руководстве](USER_GUIDE.md), [расчётных границах](CALCULATION_SPEC.md)
и [журнале](../../planning/evgeny-feedback-implementation-plan-2026-09-28.md).
Числа 20 и 3 робота на слайде 7 — контрольные изолированные случаи склада
2 000/220 паллет в сутки, 120 м, 2×10 ч; это авторский тестовый профиль,
не закупочный расчёт объекта. Денежные величины на слайдах не придуманы:
покупка/RaaS представлены как механизм, без обещанной окупаемости.

Слайд 6: [warehouse-intake.png](presentation-assets/warehouse-intake.png) —
локальный Chrome после E8, типовой ввод склада. Слайд 11:
[guest-simulation.png](presentation-assets/guest-simulation.png) — локальный
Chrome после E8, гостевой исторический авторский пример склада, не новый
v6 проектный пакет. Ещё один контрольный снимок:
[airport-intake.png](presentation-assets/airport-intake.png). Проверка браузера
6 объектов/ширин и native download PDF прошла; backup не изменён.

Ссылки в конце слайдов соответствуют `origin`, UI и введённым контактам.

наличие текста ссылки на слайде не подтверждает публикацию репозитория.
