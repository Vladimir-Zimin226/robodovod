# Правки после записи демо · 28.09.2026

## Переход от визуализации к экономике

При сохранении экономики экран результата пересоздавался и эффект в `App.jsx`
прокручивал страницу к началу при каждом изменении `result`. Кроме того,
технический, частичный и полный результаты владели своими экземплярами
`Simulation2DReport`. После перехода пользователь видел новую сцену в начале
экрана вместо рассчитанных денежных итогов.

Теперь один блок визуализации принадлежит экрану результата. Он повторно
использует техническую симуляцию только при совпадении проекта и исходного
capacity run; иначе показывает одну сцену из сохранённого экономического run.
После кнопки «Рассчитать и сохранить выбранный уровень» экран переводится к
началу денежных итогов ниже сцены. К 2D/3D можно прокрутить вверх или нажать
«К 2D и 3D». Вкладка 3D выгружает iframe при переключении на 2D или уходе
с результата. Сохранённые отчёты и исторические runs не изменены.

## Полная страница методологии

В разделе «Экономика» карточка перехода расположена после словаря терминов.
Маршрут `#economics-methodology` открывает самостоятельную адаптивную страницу
с 16 разделами, содержанием, формулами, тремя логическими таблицами и
референсными числовыми допущениями. Основа — документ
`Разобрать/Версии проекта от Жени/Методология и расчёты платформы подбора
роботизированных решений.docx`; оригинал не изменён.

Текущий продукт и референс документа названы отдельно. В частности, основной
денежный маршрут сейчас не рассчитывает налог на прибыль и перенос убытков,
не применяет единую ставку НДС к gross ценам; 2 % RaaS, 15 % дисконтирования
и отраслевые проценты не выдаются за универсальные параметры. Для операций
без подтверждённого профиля производительности не создаётся ложная
рекомендация парка.

## Проверки и границы

- Frontend: тесты, ESLint, сборка
- Headless Chrome: словарь → 16 разделов → возврат, ширина 390 px без
  горизонтального переполнения
- Read-only backup fixtures: по одной симуляции для сохранённых результатов
  аэропорта и склада; после перехода по навигации 3D iframe удаляется

Кнопка сохранения экономики проверена по компонентам и контракту результата;
живой авторизованный сценарий на production в этой работе не запускался.
Новых миграций БД нет. Backup использован только для чтения.
