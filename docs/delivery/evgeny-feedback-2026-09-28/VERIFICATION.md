# Проверки и предел результата

Исходный read-only аудит: [baseline-audit.json](baseline-audit.json),
[protected-hashes.json](protected-hashes.json). Manifest backup: 31 файл,
65 runs, из них 64 успешных; 31 simulation artifact. Запуск
`python scripts/evgeny_audit.py` проверяет member SHA/число строк,
снимки runs и защищённые исходники без восстановления БД.

Проверки этапов и фактические числа перечислены в
[журнале E1–E10](../../planning/evgeny-feedback-implementation-plan-2026-09-28.md).
`backend/test_evgeny_project.py` покрывает парк 0/1/10/20/21,
1/2/3 смены, доли 0/0.5/1, неизвестную цену, процентные режимы и
сохранение физического C11 при денежных what-if. `backend/test_picking_study.py`
проверяет отдельные единицы отбора. Frontend тесты запускаются через
`npm.cmd test`, lint — `npm.cmd exec -- eslint src tests`, сборка —
`npm.cmd run build`.

Пределы: подтверждение зарядки/долива, реальная производительность уборки,
доля ручных операций, поставка и стоимость требуют обследования/предложения.
Работники не считаются автоматически уволенными. Синтетическая комплектация
не даёт реального кандидата. Гостевой пакет предыдущего выпуска использует
авторский прямой C16; сохранённые исторические PDF/ZIP/manifest не изменены.
Встроенный what-if пока меняет денежные входы; физические требуют C11.
Production и форма сдачи не проверялись фактическим развёртыванием/отправкой.
