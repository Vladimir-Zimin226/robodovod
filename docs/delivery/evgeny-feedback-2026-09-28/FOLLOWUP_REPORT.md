# Проверка доработок после первого развёртывания

Дата: 28.09.2026. Production, форма сдачи и исходные исторические файлы этим выпуском не изменялись. Пользователь попросил проверять работающую версию после доработки; её состояние здесь не объявляется подтверждённым.

## Зоны

Причина пропусков: видимое имя новой зоны строилось из `revisionNumber`, который увеличивается при каждом изменении формы. Теперь подпись выбирает наименьший свободный номер начиная с 2, а уникальный внутренний ID продолжает расти. После правки основной зоны первая дополнительная получает «Зона 2»; после удаления и повторного добавления освободившаяся подпись возвращается, связи процессов не переиспользуются. Зоны с пользовательскими именами не переименовываются автоматически.

## Скачиваемые шаблоны и промпт

XLSX/CSV для склада, аэропорта и клиники получили строки для доли роботизируемой работы, остаточных операций, правил диспетчерского/технического покрытия и двух режимов цены внедрения/RaaS. Промпт объясняет единицы, допустимые коды и требует оставлять неизвестное пустым; подтверждение квалификации и коммерческих условий остаётся за пользователем. Для внедрения `15` означает 15% стоимости оборудования, для RaaS `2` означает 2% цены робота **в месяц**; это сверено с серверным расчётом. Ранее скачанные книги того же формата без новых строк принимаются как частичные предложения. Сервер проверяет структуру, диапазоны и связи; загруженные значения не становятся автоматически подтверждёнными результатами.

Проверено: XLSX и CSV, пустые и типовые варианты всех трёх профилей, одинаковая нормализация; негативные случаи версии, дублирования, единиц, диапазонов, формул, макросов, размера и связей. Интервью LLM не может гарантировать заполнение реального файла любым внешним провайдером: результат нужно проверить в preview и на форме.

## Старые и новые расчёты

Локальный `backup/manifest.json` создан **28.09.2026 в 07:32:08 UTC** (18:32 по Сахалину). Это снимок до сообщения об удалении проектов, поэтому он не доказывает текущее состояние базы. В нём 1 активный проект и 41 сохранённый run; 27 полных анализов: входы v5 — 21, v4 — 3, v2 — 3, входов v6 нет. Часть исторических денежных результатов была частичной. Проверены контрольные суммы и число строк 31 JSONL-файла по манифесту, снимок не изменялся.

Новый локальный расчётный маршрут принимает v6 и по подтверждённым входам считает долю работы, новый штат и фиксированные/процентные условия. Если требуемого числа или подтверждения нет, результат остаётся частичным. **Новые расчёты будут идти по этому маршруту только после развёртывания соответствующего commit; факт установленной версии сервера здесь не подтверждён.** Удаление проекта не исправляет и не пересчитывает исторический run в backup.
